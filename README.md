## 📋 Características

- **Física Avançada**: Movimento da cobra com interpolação suave e física de mola
- **Sistema de Partículas**: Efeitos visuais elaborados para colisões e consumo de alimentos
- **Temas Visuais**: Estética luxuosa com cores personalizáveis
- **Níveis Progressivos**: Dificuldade crescente e aumento gradual de velocidade
- **Pontuação e Recordes**: Sistema de pontuação com armazenamento local
- **Controles Responsivos**: Suporte para teclado (setas e WASD) e toque em dispositivos móveis
- **Efeitos Visuais Premium**: Iluminação dinâmica, sombras e gradientes
- **Configuração Personalizada**: Opções para velocidade, tamanho do tabuleiro e aparência

## 🔧 Tecnologias Utilizadas

- JavaScript ES6+ para lógica de jogo e física
- HTML5 Canvas para renderização de alta performance
- CSS3 para interface e efeitos visuais
- jQuery para manipulação do DOM e animações
- LocalStorage para persistência de recordes
- RequestAnimationFrame para animações fluidas
- Algoritmos avançados de colisão e movimento
- Design responsivo para múltiplos dispositivos

## 🎮 Como Jogar

1. Acesse o [jogo online](https://snake-game-marcelo.netlify.app/)
2. Controles:
   - Setas direcionais ou WASD para mover a cobra
   - P para pausar/continuar
   - R para reiniciar após Game Over
   - Dispositivos móveis: controles na tela
3. Objetivos:
   - Coma os alimentos para crescer e ganhar pontos
   - Evite colidir com as paredes ou com seu próprio corpo
   - Alcance a maior pontuação possível
